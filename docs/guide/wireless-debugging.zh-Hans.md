# 无线调试设置指南 (Galaxy)

[English](wireless-debugging.md) · [한국어](wireless-debugging.ko.md) · [日本語](wireless-debugging.ja.md) · **简体中文** · [Español](wireless-debugging.es.md) · [Français](wireless-debugging.fr.md)

要让 PC 上的 Claude 通过 Wi-Fi 连接手机，请在手机上**只做一次**以下设置。之后 ADB Autolink 应用会自动开启无线调试，Claude 会自动连接。

- 截图：Galaxy S21，One UI 7（Android 15）。**截图为英文界面**，中文界面下菜单位置相同。不同机型或版本的菜单位置可能略有差异。
- 开始前，请**将 PC 和手机连接到同一个 Wi-Fi**。

## 1. 开启开发者选项

1. 打开 **设置 > 关于手机 > 软件信息**。
2. 连续点按 **编译编号** 7 次。如要求输入锁屏 PIN，请输入。看到“开发者模式已开启”即完成。

## 2. 开启无线调试

1. 打开 **设置** 最下方新出现的 **开发者选项**。
2. 向下滚动到 **调试**，打开 **无线调试** 开关。
3. 出现“要在此网络上允许无线调试吗？”时，勾选 **始终允许在此网络上使用**，然后点按 **允许**。

<p>
<img src="img/en/03-settings.png" width="270" alt="设置最下方，突出显示开发者选项">
<img src="img/en/04-devopts.png" width="270" alt="开发者选项，突出显示无线调试开关">
</p>

## 3. 与 PC 配对（每台 PC 一次）

1. 点按 **无线调试** 文字（不是开关），进入详情页面。
2. 点按 **使用配对码配对设备**。
3. 把对话框中显示的 **WLAN 配对码**（6 位）和 **IP 地址和端口** 告诉 Claude。例如：`配对 192.168.0.10:37099 123456`

<p>

<img src="img/en/06-pair.png" width="270" alt="配对对话框，突出显示配对码和 IP 地址和端口">
</p>

- 配对完成前**不要关闭对话框**。每次打开时，配对码和端口都会改变。
- 对话框中的端口与无线调试页面顶部的“IP 地址和端口”**不同**。请使用对话框中的值。

## 4. 完成

配对后，Claude 会安装 ADB Autolink 应用并完成所有设置。之后手机每次连接到允许的 Wi-Fi 时都会自动开启无线调试，Claude 会在需要时自动连接。

## 遇到问题时

| 现象 | 解决方法 |
|---|---|
| 点按编译编号没有反应 | 开发者选项可能已经开启。请确认设置最下方是否有 **开发者选项**。 |
| 配对失败 | 确认对话框仍然打开、配对码和端口是对话框中的最新值，并且 PC 和手机在同一个 Wi-Fi。 |
| 应用安装被阻止 | 关闭 **设置 > 安全和隐私 > 自动拦截程序**，并查看屏幕上是否有 Play 保护机制的确认提示。 |
| 找不到手机（Windows） | 将 Wi-Fi 网络配置文件设为 **专用**。设为公用时，手机发现（mDNS）会被阻止。 |
