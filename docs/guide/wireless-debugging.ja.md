# ワイヤレス デバッグ設定ガイド (Galaxy)

[English](wireless-debugging.md) · [한국어](wireless-debugging.ko.md) · **日本語** · [简体中文](wireless-debugging.zh-Hans.md) · [Español](wireless-debugging.es.md) · [Français](wireless-debugging.fr.md)

PC の Claude がスマートフォンにワイヤレスで接続できるよう、スマートフォンで**最初に一度だけ**以下を設定してください。以降は ADB Autolink アプリがワイヤレス デバッグを自動でオンにし、Claude が自動で接続します。

- 画面: Galaxy S21、One UI 7 (Android 15)。**画像は英語表示**ですが、メニューの位置は日本語表示でも同じです。機種やバージョンによって多少異なる場合があります。
- 始める前に、**PC とスマートフォンを同じ Wi-Fi に接続**してください。

## 1. 開発者向けオプションをオンにする

1. **設定 > 端末情報 > ソフトウェア情報** を開きます。
2. **ビルド番号** を 7 回続けてタップします。ロック画面の PIN を求められたら入力します。「開発者モードをオンにしました」と表示されれば完了です。

## 2. ワイヤレス デバッグをオンにする

1. **設定** の一番下に追加された **開発者向けオプション** を開きます。
2. **デバッグ** までスクロールし、**ワイヤレス デバッグ** のスイッチをオンにします。
3. 「このネットワークでワイヤレス デバッグを許可しますか?」と表示されたら、**このネットワークで常に許可** にチェックを入れて **許可** をタップします。

<img src="img/en/04-devopts.png" width="270" alt="開発者向けオプション、ワイヤレス デバッグのスイッチを強調">
</p>

## 3. PC とペア設定する (PC ごとに一度)

1. スイッチではなく **ワイヤレス デバッグ** の文字をタップして詳細画面を開きます。
2. **ペア設定コードによるデバイスのペア設定** をタップします。
3. ダイアログに表示された **Wi-Fi ペア設定コード** (6 桁) と **IP アドレスとポート** を Claude に伝えます。例: `ペア設定して 192.168.0.10:37099 123456`

<img src="img/en/05-wireless.png" width="270" alt="ワイヤレス デバッグ、ペア設定コードによるペア設定を強調">
<img src="img/en/06-pair.png" width="270" alt="ペア設定ダイアログ、ペア設定コードと IP アドレスとポートを強調">

- ペア設定が終わるまで **ダイアログを閉じないでください**。コードとポートは開くたびに変わります。
- ダイアログのポートは、ワイヤレス デバッグ画面上部の「IP アドレスとポート」とは **異なります**。ダイアログの値を伝えてください。

## 4. 完了

ペア設定が終わると、Claude が ADB Autolink アプリをインストールし、必要な設定をすべて済ませます。以降は許可した Wi-Fi に接続するたびにワイヤレス デバッグが自動でオンになり、Claude が必要なときに接続します。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| ビルド番号をタップしても反応しない | すでに開発者向けオプションがオンかもしれません。設定の一番下に **開発者向けオプション** があるか確認してください。 |
| ペア設定に失敗する | ダイアログが開いたままか、コードとポートがダイアログの最新の値か、PC とスマートフォンが同じ Wi-Fi かを確認してください。 |
| アプリのインストールがブロックされる | **設定 > セキュリティとプライバシー > 自動ブロッカー** をオフにし、Play プロテクトの確認画面が出ていないか確認してください。 |
| スマートフォンが見つからない (Windows) | Wi-Fi のネットワーク プロファイルを **プライベート** にしてください。パブリックではスマートフォンの検出 (mDNS) がブロックされます。 |
